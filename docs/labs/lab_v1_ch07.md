## Technical Objectives
1. Download and open Cisco Packet Tracer (free at http://mng.bz/2Kra).
2. Construct the topology for Chapter 7: IPv4 addressing.
3. Implement core CLI commands: show ip interface[interface], show ip interfacebrief, interface interface.
4. Verify operational state and capture verification output.

---

## CLI Verification Commands
- `show ip interface[interface]`
- `show ip interfacebrief`
- `interface interface`
- `ip address ip-address netmask`
- `[no] shutdown`
