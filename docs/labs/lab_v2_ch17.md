## Technical Objectives
1. Download and open Cisco Packet Tracer (free at http://mng.bz/2Kra).
2. Construct the topology for Chapter 17: Virtualization and cloud.
3. Implement core CLI commands: ip vrf name, ip vrf forwardingvrf, show ip vrf.
4. Verify operational state and capture verification output.

---

## CLI Verification Commands
- `ip vrf name`
- `ip vrf forwardingvrf`
- `show ip vrf`
- `show ip route vrfvrf`
- `ping vrfvrf ip-address`
