## Topology & Scenario Context
Deploy, configure, and verify The life of a packet inside Cisco Packet Tracer according to Jeremy McDowell's lab specifications.

---

## Technical Objectives
1. Download and open Cisco Packet Tracer (free at http://mng.bz/2Kra).
2. Construct the topology for Chapter 10: The life of a packet.
3. Implement core CLI commands: show ip route, ip routedestination-networknetmask next-hop, ip routedestination-networknetmask exit-interface.
4. Verify operational state and capture verification output.

---

## CLI Verification Commands
- `show ip route`
- `ip routedestination-networknetmask next-hop`
- `ip routedestination-networknetmask exit-interface`
- `ip routedestination-networknetmask exit-interface next-hop`
