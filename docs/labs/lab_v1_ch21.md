# Lab Simulation Guide: Volume 1 Chapter 21 - Chapter 21: IPv6 routing

## Topology & Scenario Context
Deploy, configure, and verify IPv6 routing inside Cisco Packet Tracer according to Jeremy McDowell's lab specifications.

---

## Technical Objectives
1. Download and open Cisco Packet Tracer (free at http://mng.bz/2Kra).
2. Construct the topology for Chapter 21: IPv6 routing.
3. Implement core CLI commands: ipv6 unicast-routing, ipv6 addressaddress/prefix-length, ipv6 addressprefix/prefix-lengtheui-64.
4. Verify operational state and capture verification output.

---

## CLI Verification Commands
- `ipv6 unicast-routing`
- `ipv6 addressaddress/prefix-length`
- `ipv6 addressprefix/prefix-lengtheui-64`
- `ipv6 addressaddress/prefix-length link-local`
- `ipv6 addressaddress/prefix-length anycast`
