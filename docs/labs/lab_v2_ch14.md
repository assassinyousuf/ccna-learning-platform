## Topology & Scenario Context
Deploy, configure, and verify Dynamic ARP Inspection inside Cisco Packet Tracer according to Jeremy McDowell's lab specifications.

## Technical Objectives
1. Download and open Cisco Packet Tracer (free at http://mng.bz/2Kra).
2. Construct the topology for Chapter 14: Dynamic ARP Inspection.
3. Implement core CLI commands: ip arp inspection vlan vlans, ip arp inspection validate {[ src-mac ]      dst-mac]      ip]}, ip arp inspection trust.
4. Verify operational state and capture verification output.

---

## CLI Verification Commands
- `ip arp inspection vlan vlans`
- `ip arp inspection validate {[ src-mac ]      dst-mac]      ip]}`
- `ip arp inspection trust`
- `ip arp inspection limit rate ppsburst interval seconds`
- `errdisable recovery cause arp-inspection`
