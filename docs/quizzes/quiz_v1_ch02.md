# Assessment & Review: Volume 1 Chapter 2 - Chapter 2: Network devices

### Question 1: Which device enables hosts to communicate with hosts in other LANs?
- A. Switch
- B. Firewall
- C. Router
- D. Server

> **Official Correct Answer**: **C** — C: Router  
> **Technical Explanation**: A router is a networking device that forwards data packets between computer networks, enabling communication between hosts in different local area networks (LANs).


---

### Question 2: Which of the following device types typically has many physical ports for end hosts to connect to?
- A. Router
- B. Switch
- C. Server
- D. Client

> **Official Correct Answer**: **B** — B: Switch  
> **Technical Explanation**: A switch is a device in a computer network that connects other devices together. It has multiple ports to which computers, printers, and other networking devices can be connected. A switch is used within a LAN to connect multiple devices and manage their network traffic.


---

### Question 3: What type of software runs on an end host and filters traffic entering the host?
- A. Host-based firewall
- B. Network firewall
- C. Client
- D. Server

> **Official Correct Answer**: **A** — A: Host-based firewall  
> **Technical Explanation**: A host-based firewall is a software application installed on a single computer (the host) in a network. It monitors and filters incoming and outgoing network traffic based on a set of rules.


---

### Question 4: What kind of network is used to connect remote locations?
- A. LAN
- B. WAN

> **Official Correct Answer**: **B** — B: WAN  
> **Technical Explanation**: A wide area network (WAN) is a network that extends over a large geographical area, often connecting multiple smaller networks like LANs. WANs are used to connect remote or geographically dispersed locations.


---

### Question 5: Which role describes a device that accesses services provided by another host?
- A. Router
- B. Server
- C. User
- D. Client

> **Official Correct Answer**: **D** — D: Client  
> **Technical Explanation**: A client is a computer or a program that accesses services provided by another computer (the server). The client uses the network to send requests to the server and to receive data and services in return. This client-server model is a fundamental concept in networking.
