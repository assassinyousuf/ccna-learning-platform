## 1. Chapter Overview
Prevent ARP poisoning and man-in-the-middle attacks using DAI: validate ARP packets against the DHCP Snooping binding database and static ARP ACLs.

---

## 2. Key Blueprint Objectives
- Address Resolution Protocol–based attacks such as ARP poisoning

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ip arp inspection vlan vlans` | `(config)#` | Enable DAI on thespecified VLANs. |
| `ip arp inspection validate {[ src-mac ]      dst-mac]      ip]}` | `(config)#` | Enable optional DAIchecks. |
| `ip arp inspection trust` | `(config-if)#` | Configure the port as a DAItrusted port. |
| `ip arp inspection limit rate ppsburst interval seconds` | `(config-if) #` | Rate-limit ARP messageson the port. |
| `errdisable recovery cause arp-inspection` | `(config)#` | Enable ErrDisableRecovery for ports disabledby DAI rate limiting. |
| `show ip arp inspection` | `#` | View DAI status andinformation. |
| `show ip arp inspection interfaces` | `#` | View DAI interface statusand settings. |
