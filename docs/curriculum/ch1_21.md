## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ipv6 unicast-routing` | `(config)#` | Enable IPv6 routing. |
| `ipv6 addressaddress/prefix-length` | `(config-if)#` | Configure an IPv6address. |
| `ipv6 addressprefix/prefix-lengtheui-64` | `(config-if)#` | Configure an IPv6address, using EUI-64 togenerate the host portion. |
| `ipv6 addressaddress/prefix-length link-local` | `(config-if)#` | Configure a link-local IPv6address. |
| `ipv6 addressaddress/prefix-length anycast` | `(config-if)#` | Configure an anycast IPv6address. |
| `ipv6 addressautoconfig [default]` | `(config-if)#` | Use SLAAC to generatean IPv6 address. |
