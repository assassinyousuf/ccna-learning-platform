## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ip vrf name` | `(config)#` | Create a VRF instance. |
| `ip vrf forwardingvrf` | `(config-if)#` | Assign the interface to aVRF. |
| `show ip vrf` | `#` | View a list of VRFs andtheir interfaces. |
| `show ip route vrfvrf` | `#` | View the specified VRF'srouting table. |
| `ping vrfvrf ip-address` | `#` | Ping a host from thespecified VRF. |
