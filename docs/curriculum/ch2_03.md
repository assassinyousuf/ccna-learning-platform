## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ip domain lookup` | `(config)#` | Enable the device to sendDNS queries. |
| `ip name-serverip-address` | `(config)#` | Configure the DNSserver(s) to send DNS |
| `ip dns server` | `(config)#` | Configure the device as aDNS server, allowing it torespond to DNS queries. |
| `ip domain name domain-name` | `(config)#` | Set the device's defaultdomain name. |
| `ip hosthostname ip-address` | `(config)#` | Create a manual name-to-IPmapping. |
| `show hosts` | `#` | View all name-to-IPmappings. |
