## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `show clock[ detail ]` | `#` | View the time of thesoftware clock. |
| `clock sethh : mm : ss month dayyear` | `#` | Set the time of the softwareclock. |
| `show calendar` | `#` | View the time of thehardware calendar. |
| `calendar sethh : mm : ssmonthday year` | `#` | Set the time of the hardwarecalendar. |
| `clock update-calendar` | `#` | Sync the calendar to theclock's time. |
| `clock read-calendar` | `#` | Sync the clock to thecalendar's time. |
| `clock timezone name hours-offsetminutes-offset` | `(config)#` | Set the device’s timezone. |
| `clock summer-time name  recurringstart-date-time end-date-time` | `(config)#` | Enable summer time(daylight saving time). |
| `ntp server ip-address[ prefer]` | `(config)#` | Configure this device as anNTP client of the specifiedserver. |
| `ntp update-calendar` | `(config)#` | Use NTP to regularlyupdate the calendar. |
| `ntp source interface` | `(config)#` | Set the interface used tosend NTP messages. |
| `ntp master  [ stratum]` | `(config)#` | Make this device a primaryNTP server with its ownclock as the referenceclock. |
| `ntp peer ip-address` | `(config)#` | Configure a symmetricactive NTP relationship ontwo devices. |
| `ntp authentication-keykey-numbermd5key` | `(config)#` | Configure an NTPauthentication key. |
| `ntp trusted-keykey-number` | `(config)#` | Specify an NTP trustedauthentication key. |
| `ntp serverip-addresskeykey-number` | `(config)#` | Configure this device as anNTP client of the specifiedserver and authenticate itwith the specified key. |
| `show ntp associations` | `#` | View a list of NTPassociations (timesources). |
| `show ntp status` | `#` | View the device's NTPstatus. |
