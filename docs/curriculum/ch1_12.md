## 1. Chapter Overview
Configure VLANs, access ports, 802.1Q trunk ports, native VLANs, and Inter-VLAN routing using Router-on-a-Stick (ROAS) and Multilayer Switch SVIs.

## 2. Key Blueprint Objectives

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `show vlan brief` | `#` | View a list of VLANs andassociated ports. |
| `show interfacestrunk` | `#` | View a list of trunk ports. |
| `vlan vlan-id` | `(config)#` | Configure a VLAN. |
| `name name` | `(config-` | Name the VLAN. |
| `[no] shutdown` | `(config-vlan)#` | Enable/disable the VLAN. |
| `switchport mode{access \| trunk}` | `(config-if)#` | Manually configureaccess or trunk mode. |
| `switchport accessvlan vlan-id` | `(config-if)#` | Set the port's accessVLAN. |
| `switchport trunkencapsulation dot1q` | `(config-if)#` | Set the port's trunkencapsulation protocol. |
| `switchport trunkallowed vlan {vlansadd vlans \| removevlans \| except vlansall \| none}` | `(config-if)#` | Specify or modify theport's list of allowedVLANs (when in trunkmode). |
| `switchport trunknative vlan vlan-id` | `(config-if)#` | Specify the port's nativeVLAN. |
| `interfaceinterface.subif-number` | `(config)#` | Configure a subinterface(ROAS). |
| `encapsulation dot1qvlan [native]` | `(config-subif)#` | Specify the subinterface'sVLAN ID. |
| `ip routing` | `(config)#` | Enable IP routing on amultilayer switch. |
| `interface vlan vlan-id` | `(config)#` | Configure a switch virtualinterface (SVI). |
| `no switchport` | `(config-if)#` | Make the port a Layer 3routed port. |
