## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ip nat inside` | `(config-if) #` | Configure an insideinterface. |
| `ip nat outside` | `(config-if)#` | Configure an outsideinterface. |
| `ip nat inside source staticinside-local inside-global` | `(config)#` | Configure a static NATmapping. |
| `ip nat pool pool-name start-ip end-ipprefix-lengthlength` | `(config)#` | Create a NAT pool. |
| `ip nat inside source listaclpoolpool-name` | `(config)#` | Configure a dynamic NATmapping of an ACL to aNAT pool. |
| `ip nat inside source listaclpoolpool-nameoverload` | `(config)#` | Configure a dynamic PAT(NAT overload) mapping ofan ACL to a NAT pool. |
| `ip nat inside source list  aclinterfaceinterface     overload]` | `(config)#` | Configure a dynamic PATmapping of an ACL to aninterface IP address. |
| `show ip nat translations` | `#` | View the NAT translationtable. |
| `show ip nat statistics` | `#` | View NAT translationstatistics. |
