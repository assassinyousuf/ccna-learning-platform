## 1. Chapter Overview
Configure Cisco Wireless LAN Controllers (WLC) via GUI and CLI: create dynamic interfaces, configure WLANs, apply WPA2/WPA3 security policies, and associate LWAPs.

## 2. Key Blueprint Objectives

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `option 42 ipip-address` | `(dhcp-config)#` | Set the DHCP pool's NTPserver address. |
| `option 43 ipip-address` | `(dhcp-config)#` | Set the DHCP pool's WLCaddress (to help LWAPsidentify their WLC). |
