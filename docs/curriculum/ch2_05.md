# Volume 2 Chapter 5: Chapter 5: Secure Shell

**Certification Domain**: Security Fundamentals  
**Estimated Study Time**: 39 min Minutes  

---

## 1. Chapter Overview
Secure device management access by replacing unencrypted Telnet with SSH: generate RSA cryptographic keys, configure local usernames, and vty line transport.

---

## 2. Key Blueprint Objectives
- Securing access to a device’s console port

---

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `username usernamesecretpassword` | `(config)#` | Create a local useraccount. |
| `line console 0` | `(config)#` | Configure the consoleline. |
| `line vty 0 15` | `(config)#` | Configure all 16 VTYlines. |
| `passwordpassword` | `(config-line)#` | Configure a linepassword. |
| `login` | `(config-line)#` | Require a user to providethe line password to accessthe line. |
| `login local` | `(config-line)#` | Require a user to log inwith a local user account toaccess the line. |
| `exec-timeoutminutes` | `(config-line)#` | Set the inactivity logouttimer. |
| `transport input  {telnet」ssh」all    none}` | `(config-line)#` | Set the protocols that can beused to connect to theline. |
| `access-classaclin` | `(config-line)#` | Apply an ACL to limitaccess to the line. |
| `ip default-gatewayip-address` | `(config)#` | Set the Layer 2 switch'sdefault gateway. |
| `show ip default-gateway` | `#` | View the Layer 2 switch'sdefault gateway. |
| `show ip ssh` | `#` | View SSH settings andinformation. |
| `crypto key generate rsa` | `(config)#` | Generate an RSA key pair(for SSH). |
| `ip ssh version 2` | `(config)#` | Allow only SSH version 2connections. |
