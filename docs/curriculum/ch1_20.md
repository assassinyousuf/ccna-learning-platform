## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ipv6 unicast-routing` | `(config)#` | Enable IPv6 routing. |
| `ipv6 addressaddress/prefix-length` | `(config-if)#` | Configure an IPv6address. |
| `ipv6 addressprefix/prefix-lengtheui-64` | `(config-if)#` | Configure an IPv6address, using EUI-64 togenerate the host portion. |
| `ipv6 addressaddress/prefix-length link-local` | `(config-if)#` | Configure a link-local IPv6address. |
| `ipv6 addressaddress/prefix-length anycast` | `(config-if)#` | Configure an anycast IPv6address. |
| `ipv6 addressautoconfig [default]` | `(config-if)#` | Use SLAAC to generatean IPv6 address. |
| `ipv6 enable` | `(config-if)#` | Enable IPv6 on theinterface withoutconfiguring an IPv6address. |
| `show ipv6 interface` | `#` | View a concise summaryof interface IPv6 |
| `brief` | `` | addresses and status. |
| `show ipv6 interface [interface]` | `#` | View detailed Layer 3 information about IPv6 interfaces. |
| `show ipv6 neighbors` | `#` | View the IPv6 neighbor table (like ARP). |
| `show ipv6 route` | `#` | View the IPv6 routing table. |
| `ipv6 route destination-prefix next-hop [ad]` | `(config)#` | Configure a recursive static route. |
| `ipv6 route destination-prefix exit-interface [ad]` | `(config)#` | Configure a directly connected static route. |
| `ipv6 route destination-prefix exit-interface next-hop [ad]` | `(config)#` | Configure a fully specified static route. |
