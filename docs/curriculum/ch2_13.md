## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `ip dhcp snooping` | `(config)#` | Enable DHCP Snooping. |
| `ip dhcp snooping vlan vlans` | `(config)#` | Activate DHCP Snoopingon VLANs. |
| `no ip dhcp snooping informationoption` | `(config)#` | Disable option 82insertion. |
| `ip dhcp snooping trust` | `(config-if)#` | Configure the port as aDHCP Snooping trustedport. |
| `ip dhcp snooping limit ratepps` | `(config-if)#` | Rate-limit DHCP messageson the port. |
| `errdisable recovery cause dhcp-rate-limit` | `(config)#` | Enable ErrDisableRecovery for ports disabledby DHCP Snooping ratelimiting. |
| `show ip dhcp snooping` | `#` | View DHCP Snoopingstatus and settings. |
| `show ip dhcp snooping binding` | `#` | View the DHCP Snoopingbinding table. |
