# Volume 1 Chapter 24: Chapter 24: Extended access control lists

**Certification Domain**: Security Fundamentals  
**Estimated Study Time**: 32 min Minutes

## 1. Chapter Overview
Deep traffic filtering with extended ACLs (100-199, 2000-2699): match protocols (IP, TCP, UDP, ICMP), source/destination IPs, TCP/UDP port operators (eq, gt, lt, range), and ACE resequencing.

---

## 2. Key Blueprint Objectives
- The various parameters extended access control lists use to match packets

---

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `access-list number {permit \| deny} src-ip wildcard` | `(config)#` | Configure an ACE in a standard numbered ACL. |
| `access-list number remark remark` | `(config)#` | Configure an ACL remark. |
| `ip access-list standard name` | `(config)#` | Configure a standard named ACL. |
| `[seq] {permit \| deny} src-ip wildcard` | `(config-std-nacl)#` | Configure an ACE in the standard named ACL. |
| `access-list number {permit \| deny} protocol source destination` | `(config)#` | Configure an ACE in an extended numbered ACL, matching based on protocol and source/destination IP. |
| `access-list number {permit \| deny} {tcp\|udp} source [operator src-port] destination [operator dst-port]` | `(config)#` | Configure an ACE in an extended numbered ACL, matching based on protocol, src/dst IP, and src/dst port. |
