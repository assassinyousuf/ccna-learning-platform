## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `show spanning-tree` | `#` | View STP status andinformation. |
| `spanning-tree vlanvlan prioritypriority` | `(config)#` | Set the STP bridgepriority. |
| `spanning-tree vlanvlan root primary` | `(config)#` | Set the bridge priority to24576, or the lowestincrement of 4096needed to become theroot bridge. |
| `spanning-tree vlanvlan root secondary` | `(config)#` | Set the bridge priority to28672. |
| `spanning-tree vlanvlan port-prioritypriority` | `(config-if)#` | Set the STP port priority. |
| `spanning-treeportfast enable` | `(config-if)#` | Enable PortFast on theport. |
