# Volume 2 Chapter 7: Chapter 7: Syslog

**Certification Domain**: IP Services  
**Estimated Study Time**: 34 min Minutes  

---

## 1. Chapter Overview
Configure centralized logging: Syslog message structure, 8 severity levels (0 Emergencies to 7 Debugging), timestamping, and sending log buffers to external syslog servers.

---

## 2. Key Blueprint Objectives
- Real-time logging to the console and VTY lines

---

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `terminal monitor` | `#` | Enable real-time logging tothe VTY lines for thecurrent session. |
| `logging console[ severity ]` | `(config)#` | Configure logging to theconsole line. |
| `logging monitor[ severity ]` | `(config)#` | Configure logging to theVTY lines. |
| `logging buffered[ bytes ]severity]` | `(config)#` | Configure logging to thelogging buffer. |
| `logging trap[ severity ]` | `(config)#` | Configure logging to aSyslog server. |
| `logging[ host ]ip-address` | `(config)#` | Specify the Syslog server tosend logs to. |
| `service timestamps log datetime[ localtime ] [ msec ]` | `(config)#` | Timestamp log messageswith the current date andtime. |
| `service timestamps log uptime` | `(config)#` | Timestamp log messageswith the device's currentuptime. |
| `logging synchronous` | `(config-line)#` | Automatically reprint thecurrent command on a newline if cut off by a logmessage. |
| `show logging` | `#` | Show Syslog settings andthe logging buffer. |
| `show memory` | `#` | Show device memoryusage. |
| `debugcommand` | `#` | Display detailed real-timeinformation about variousoperations/events. |
