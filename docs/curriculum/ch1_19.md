## 1. Chapter Overview
Implement default gateway redundancy with HSRP (Hot Standby Router Protocol), VRRP, and GLBP: virtual IP/MAC addresses, priority, and preemption.

---

## 2. Key Blueprint Objectives

## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `standby group ipvirtual-ip` | `(config-if)#` | Set the HSRP virtual IPaddress. |
| `standby grouppriority priority` | `(config-if)#` | Set the HSRP priority. |
| `standby grouppreempt` | `(config-if)#` | Enable HSRP preemption. |
| `standby version 2` | `(config-if)#` | Enable HSRP version 2. |
| `show standby [brief]` | `#` | View HSRP status andinformation. |
