## 3. Cisco IOS Command Reference
| Command | Mode | Operational Purpose |
| :--- | :--- | :--- |
| `snmp-server community password ro` | `(config)#` | Configure a read-onlycommunity string. |
| `snmp-server communitypassword rw` | `(config)#` | Configure a read-writecommunity string. |
| `snmp-server enable traps` | `(config)#` | Enable SNMP traps. |
| `snmp-server host  ip-addressversion 2c      community-string` | `(config)#` | Specify the NMS to sendtraps to. |
